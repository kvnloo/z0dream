---
name: dream
description: Create and recursively zoom into images with z0dream.
---

Use z0dream when the user asks for a recursively detailed, zoomable, gigapixel-like, or "dream deeper" image experience.

- Start a new scene with `dream_image`.
- Prefer letting the user select regions in the z0dream UI for `dream_deeper` rather than inventing coordinates.
- Describe resolution as "equivalent resolved detail" unless a literal flattened bitmap of that size exists.
- Preserve the original scene identity and continuity when recursively refining a region.
