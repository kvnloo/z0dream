# z0dream Privacy Notice (development preview)

Last updated: 2026-09-30

z0dream processes prompts and generated image data only to provide the requested recursive-image experience. The development build stores dream metadata and generated assets on the server running z0dream. It does not include advertising trackers or sell user data.

When `Z0DREAM_PROVIDER=openai` is enabled, prompts and image crops required for generation are sent to OpenAI's API under the operator's OpenAI account and applicable OpenAI terms. The `mock` provider makes no image-generation API calls.

This development notice must be reviewed and updated before a public Plugin Directory launch, particularly after authentication, hosted storage, analytics, or additional model providers are introduced.
